    Backup e restauração

    Exporte um pacote Ledgerly .lgp com central.db + daily.db para restauração conjunta. Também é possível baixar cada banco SQLite separadamente para consulta em programas como DB Browser for SQLite. Os arquivos não são criptografados: guarde-os em local seguro.
